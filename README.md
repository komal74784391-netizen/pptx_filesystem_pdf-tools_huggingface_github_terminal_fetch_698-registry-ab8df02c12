# Lumen Analytics — AI Data Governance Registry

This repository is the source of truth for corpus intake clearance at Lumen Analytics.

Layout:

- `policy/license_policy.md` — the corpus licence-clearance policy in force.
- `inbox/` — intake cards submitted with each corpus artifact.
- `records/` — published provenance records (one JSON document per intake).
- `registry/approved_datasets.json` — upstream datasets cleared for training use.

All edits to this repository are reviewed by the AI Governance team.
